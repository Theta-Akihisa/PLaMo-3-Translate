はじめに — macOS アプリと接続する

この拡張機能は、Mac で動く「PLaMo Translate」アプリを翻訳エンジンとして使います。翻訳はすべてお使いの Mac の中で行われます。

  1. macOS アプリをインストールして起動
    「PLaMo Translate」アプリをインストールして起動します（インストール方法）。アプリの API サーバーは既定で有効で、127.0.0.1:18080 で待ち受けます。
  2. アプリでモデル（0.8B）をダウンロード
    アプリの「モデル」画面で 0.8B（約 573 MB）をダウンロードします。より高精度な 2B / 8B は後から追加できます。
  3. 接続テスト

既定はポート 18080。アプリの設定でポートを変えた場合はここも合わせてください。

モデル

macOS アプリで使うモデルを選びます。アプリ側で切り替えた場合はアプリの選択が優先されます。未ダウンロードのモデルはアプリの「モデル」画面でダウンロードしてください。

macOS アプリに接続するとモデルの一覧が表示されます

llama-server では、サーバーを起動したときのモデルが使われます（ここでの選択は表示と起動スクリプト引数の目安です）。
